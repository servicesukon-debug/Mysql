# Peterjunior Hospital Database Assessment

**Module:** CPU4:103 – Introduction to Database

## Project Overview
This project demonstrates the design and implementation of a relational database for a hospital management system.

## Project Contents
- `01_schema.sql` – Creates the database tables and relationships.
- `01b_sample_data.sql` – Inserts sample data.
- `02_individual_queries.sql` – Contains individual SQL queries.
- `03_procedure_and_trigger.sql` – Contains stored procedures and triggers.
- `04_security.sql` – Demonstrates database security.

## Database Tools
- MySQL
- MySQL Workbench
